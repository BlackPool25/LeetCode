

# 225. Implement Stack using Queues

## 1. Problem Statement

> Implement a last-in-first-out (LIFO) stack using only two queues. The implemented stack should support all the functions of a normal stack (`push`, `pop`, `top`, and `empty`).

> **Example 1:**  
Input: `["MyStack", "push", "push", "top", "pop", "empty"]`  
`[[], [1], [2], [], [], []]`  
Output: `[null, null, null, 2, 2, false]`  
Explanation:  
`MyStack myStack = new MyStack();`  
`myStack.push(1);`  
`myStack.push(2);`  
`myStack.top(); // return 2`  
`myStack.pop(); // return 2`  
`myStack.empty(); // return False`

> **Example 2:**  
Input: `["MyStack", "push", "top", "pop", "empty"]`  
`[[], [5], [], [], []]`  
Output: `[null, null, 5, 5, false]`

## 2. Constraints & Key Observations

- **Constraints:**
    - `1 <= x <= 9`
    - At most `100` calls will be made to `push`, `pop`, `top`, and `empty`.
    - All the calls to `pop` and `top` are valid.

- **What constraints tell us:**
    - The small number of operations (`<= 100`) allows even O(n) operations per call to be acceptable.
    - No need to optimize for worst-case scenarios with large input sizes.

- **Key observations:**
    - Each `push` operation must ensure the new element is at the **front** of the primary queue to simulate LIFO behavior.
    - The `pop` and `top` operations can be done in O(1) time if the top of the stack is at the front of the queue.

- **Edge cases to handle (based on actual constraints):**
    - Single-element stack (e.g., push once, then pop).
    - All operations are `push` and `empty` (no `pop` or `top`).
    - No need to handle invalid `pop`/`top` calls (as per problem statement).

## 3. Solution Development

### 3.1 Core Intuition

- **The "Aha!" moment:**  
  To simulate a stack with queues, we can use **two queues** to maintain the LIFO order. Every time a new element is pushed, it is placed at the **front** of the primary queue by transferring all existing elements to the secondary queue.

- **Algorithm invariant:**  
  At any time, `q1` contains the stack elements in **reverse order**, with the top of the stack at the **front** of `q1`.

- **Why this works:**  
  By moving all existing elements to the secondary queue before pushing the new element, we ensure the new element is always at the front of the primary queue. This allows `pop` and `top` to be O(1) operations.

---

### 3.2 Algorithm Strategy

1. **Use two queues (`q1` and `q2`)** to maintain the stack state.
2. **For `push(x)`:**
    - Push `x` to `q2`.
    - Move all elements from `q1` to `q2`.
    - Swap `q1` and `q2` (so `q1` now holds the updated stack).
3. **For `pop()` and `top()`:**
    - Directly access the front of `q1` (since it contains the top of the stack).
4. **For `empty()`:**
    - Check if `q1` is empty.

## 4. Example Walkthrough (Two-Queue Implementation)

**Input:** `push(1)`, `push(2)`, `top()`, `pop()`, `empty()`

- **Step 1:** `push(1)`  
    - `q2.push(1)` → `q2 = [1]`  
    - `q1` is empty → no elements to move  
    - Swap `q1` and `q2` → `q1 = [1]`, `q2 = []`

- **Step 2:** `push(2)`  
    - `q2.push(2)` → `q2 = [2]`  
    - Move `q1` elements to `q2`:  
        - `q1.pop()` → `1` → `q2.push(1)` → `q2 = [2, 1]`  
    - Swap `q1` and `q2` → `q1 = [2, 1]`, `q2 = []`

- **Step 3:** `top()`  
    - Return `q1.front()` → `2`

- **Step 4:** `pop()`  
    - Remove `q1.front()` → `2`  
    - `q1 = [1]`

- **Step 5:** `empty()`  
    - `q1` is not empty → return `false`

## 5. Complexity Analysis

- **Time Complexity:**
    - **Two-Queue Implementation:**  
        - `push(x)`: O(n) (moving all elements from `q1` to `q2`)  
        - `pop()`, `top()`, `empty()`: O(1)  
    - **One-Queue Implementation:**  
        - `push(x)`: O(n) (rotating the queue)  
        - `pop()`, `top()`, `empty()`: O(1)  
    - **Total Time:** O(n) per `push`, but acceptable due to small input size (≤ 100 operations).

- **Space Complexity:**  
    - O(n) for both implementations (all elements are stored in the queues).

## 6. Code Implementation

### Two-Queue Implementation

```cpp
class MyStack {
public:
    queue<int> q1, q2;

    MyStack() {}

    void push(int x) {
        q2.push(x);
        while (!q1.empty()) {
            q2.push(q1.front());
            q1.pop();
        }
        swap(q1, q2);
    }

    int pop() {
        int top = q1.front();
        q1.pop();
        return top;
    }

    int top() {
        return q1.front();
    }

    bool empty() {
        return q1.empty();
    }
};
```

### One-Queue Implementation

```cpp
class MyStack {
public:
    queue<int> q1;

    MyStack() {}

    void push(int x) {
        int num_of_elements = q1.size();
        q1.push(x);
        for (int i = 0; i < num_of_elements; ++i) {
            q1.push(q1.front());
            q1.pop();
        }
    }

    int pop() {
        int top = q1.front();
        q1.pop();
        return top;
    }

    int top() {
        return q1.front();
    }

    bool empty() {
        return q1.empty();
    }
};
```
