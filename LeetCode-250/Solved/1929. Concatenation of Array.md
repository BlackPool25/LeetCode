

# 1929. Concatenation of Array

## 0. Problem Metadata

- **Difficulty:** Easy  
- **Topics/Tags:** Array, Duplication  
- **Pattern Category:** Array Duplication - Direct Copy  

---

## 1. Problem Statement

Given an array `nums` of length `n`, return a new array `ans` of length `2n` such that `ans[i] = nums[i]` for `0 ≤ i < n`, and `ans[i + n] = nums[i]` for `0 ≤ i < n`.

### Example 1:
**Input:** `nums = [1, 2, 3]`  
**Output:** `[1, 2, 3, 1, 2, 3]`

### Example 2:
**Input:** `nums = [0]`  
**Output:** `[0, 0]`

---

## 2. Constraints and Key Observations

- **Constraints:**  
  - `1 ≤ nums.length ≤ 1000`  
  - `-10^4 ≤ nums[i] ≤ 10^4`  

- **Key Observations:**  
  - The output array is simply the input array concatenated with itself.  
  - No sorting, rotation, or transformation is required.  
  - Edge cases include when `n = 1` (e.g., `[0]` → `[0, 0]`).  

---

## 3. Solution Development

### Core Intuition
The problem requires a **direct duplication** of the input array. The output array is formed by appending the input array to itself.

### Algorithm Strategy
1. Create a new array `ans` of size `2 * n`.  
2. Iterate through the input array `nums` and copy each element to both the first and second halves of `ans`.  

---

## 4. Example Walkthrough

**Input:** `nums = [1, 2, 3]`  
**Output:** `[1, 2, 3, 1, 2, 3]`  

**Steps:**
1. Initialize `ans = [0, 0, 0, 0, 0, 0]` (size 6).  
2. For `i = 0`:  
   - `ans[0] = 1`  
   - `ans[3] = 1`  
3. For `i = 1`:  
   - `ans[1] = 2`  
   - `ans[4] = 2`  
4. For `i = 2`:  
   - `ans[2] = 3`  
   - `ans[5] = 3`  

---

## 5. Complexity Analysis

- **Time Complexity:** $O(n)$  
  - A single loop runs `n` times.  
- **Space Complexity:** $O(n)$  
  - The output array `ans` has size `2n`.  

> Note: The user's original analysis stated $O(1)$ space, but this is incorrect. The output array is part of the solution and contributes to the space complexity.  

---

## 6. Code Implementation

```cpp
vector<int> ans(2 * n); // Create an array of size 2n

for (int i = 0; i < n; i++) {
    ans[i] = nums[i];          // Copy the first half
    ans[i + n] = nums[i];      // Copy the second half
}
```

## 7. Pattern Recognition

### **Pattern Name:** Array Duplication - Direct Copy  
### **Reusable Framework:**
```cpp
vector<int> duplicateArray(vector<int>& nums) {
    int n = nums.size();
    vector<int> result(2 * n);
    for (int i = 0; i < n; i++) {
        result[i] = nums[i];
        result[i + n] = nums[i];
    }
    return result;
}
```

### **Key Insights:**
- This pattern is useful for problems requiring **exact duplication** of an array.  
- The solution is **linear in time** and **linear in space**.  

### **Common Mistakes:**
- Forgetting to use `i + n` for the second half.  
- Misunderstanding the output size (must be `2n`).
