## 1. Problem Statement

> **Given an integer array `nums` sorted in non‑decreasing order, remove the duplicates in‑place such that each unique element appears only once. The relative order of the elements should be kept the same.**  
> Consider the number of unique elements in `nums` to be `k`. After removing duplicates, return the number of unique elements `k`.  
> The first `k` elements of `nums` should contain the unique numbers in sorted order. The remaining elements beyond index `k‑1` can be ignored.

## 3. Solution Development

### 3.1 Core Intuition

- **Aha! moment:** Because the array is sorted, duplicates are contiguous. We can keep a “write” pointer (`i`) that tracks the position of the last unique element, and a “read” pointer (`j`) that scans the array.  
- **Algorithm invariant:** At any time, `nums[0…i]` contains the unique elements seen so far, in order.  
- **Why this works:** Whenever we encounter a new value (`nums[j] != nums[i]`), we increment `i` and copy the new value into `nums[i]`. This guarantees that after the loop, the first `i+1` positions hold all unique values.

### 3.2 Algorithm Strategy

1. Initialize `i = 0` to point at the first element (the first unique value).  
2. Iterate `j` from `0` to `nums.size() - 1`.  
3. If `nums[j]` differs from `nums[i]`, we have found a new unique value:
   - Increment `i`.
   - Overwrite `nums[i]` with `nums[j]`.  
4. After the loop, return `i + 1` as the count of unique elements.

## 4. Example Walkthrough

**Trace through Example 1: `nums = [1,1,2]`**

- **Initial state:** `i = 0`, `nums = [1,1,2]`.
- **Iteration j = 0:** `nums[0] == nums[0]` → no action.
- **Iteration j = 1:** `nums[1] == nums[0]` → duplicate, no action.
- **Iteration j = 2:** `nums[2] != nums[0]` → new unique:
  - `i` becomes `1`.
  - `nums[1]` is set to `2` → `nums = [1,2,2]`.
- **End of loop:** `i = 1`, so return `i + 1 = 2`.  
  The first two elements are `[1,2]`, as required.

**Trace through Example 2: `nums = [0,0,1,1,1,2,2,3,3,4]`**

- `i = 0` (value `0`).
- j=1: duplicate → skip.
- j=2: new (`1`): `i=1`, `nums[1]=1`.
- j=3,4: duplicates of `1` → skip.
- j=5: new (`2`): `i=2`, `nums[2]=2`.
- j=6: duplicate of `2` → skip.
- j=7: new (`3`): `i=3`, `nums[3]=3`.
- j=8: duplicate of `3` → skip.
- j=9: new (`4`): `i=4`, `nums[4]=4`.
- Return `i+1 = 5`. The array now starts `[0,1,2,3,4,…]`.

## 5. Complexity Analysis

- **Time Complexity:** \(O(n)\)  
  - We perform a single pass over the array (`n` iterations), each iteration doing constant‑time work.
- **Space Complexity:** \(O(1)\)  
  - Only two integer indices are used; no additional data structures are allocated.

## 6. Code

```cpp
class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        int i = 0;
        for (int j = 0; j < nums.size(); j++) {
            if (nums[j] != nums[i]) {
                i++;
                nums[i] = nums[j];
            }
        }
        return i + 1;
    }
};
```

## 7. Pattern Recognition

### Reusable Structure

```cpp
int i = 0;                     // write pointer at last unique element

```

- **`i`** always points to the last unique element written.  
- **`j`** scans every element.  
- The condition `array[j] != array[i]` detects a new unique value because the array is sorted.  
- The algorithm maintains the invariant that `array[0…i]` holds all unique values seen so far.

- Use a fast‑slow pointer approach when the input is sorted and you need to eliminate consecutive duplicates.

- This pattern guarantees \(O(n)\) time and \(O(1)\) space, making it ideal for large arrays.
