

# 1768. Merge Strings Alternately

## 1. Problem Statement

> You are given two strings `word1` and `word2`. Merge the strings by adding letters in alternating order, starting with `word1`. If a string is longer than the other, append the additional letters onto the end of the merged string. Return the merged string.

**Example 1:**  
Input: `word1 = "abc"`, `word2 = "pqr"`  
Output: `"apbqcr"`  
Explanation: The merged string will be merged as so:  
`word1`:  `a`   `b`   `c`  
`word2`:    `p`   `q`   `r`  
`merged`: `a p b q c r`

**Example 2:**  
Input: `word1 = "ab"`, `word2 = "pqrs"`  
Output: `"apbqrs"`  
Explanation: Notice that as `word2` is longer, `"rs"` is appended to the end.  
`word1`:  `a`   `b`  
`word2`:    `p`   `q`   `r`   `s`  
`merged`: `a p b q   r   s`

**Example 3:**  
Input: `word1 = "abcd"`, `word2 = "pq"`  
Output: `"apbqcd"`  
Explanation: Notice that as `word1` is longer, `"cd"` is appended to the end.  
`word1`:  `a`   `b`   `c`   `d`  
`word2`:    `p`   `q`  
`merged`: `a p b q c   d`

## 2. Constraints & Key Observations

- **Constraints:**  
    - `1 <= word1.length, word2.length <= 100`  
    - `word1` and `word2` consist of lowercase English letters.  

- **What constraints tell us:**  
    - Both strings are guaranteed to be non-empty, so no need to handle empty inputs.  
    - Maximum combined length is 200, so even O(n²) algorithms would be acceptable, but O(n) is preferred.  

- **Key observations:**  
    - The merged string alternates characters from `word1` and `word2` until one is exhausted.  
    - The remaining characters from the longer string are appended at the end.  
    - The order of appending is strictly `word1` first, then `word2`.  

- **Edge cases to handle (based on actual constraints):**  
    - One string is significantly longer than the other (e.g., `word1 = "a"`, `word2 = "bcdefg"`).  
    - Both strings are of equal length (e.g., `word1 = "ab"`, `word2 = "cd"`).  
    - One string is completely exhausted before the other (e.g., `word1 = "a"`, `word2 = "bc"`).

## 3. Solution Development

### 3.1 Core Intuition

- **The "Aha!" moment:** The problem can be solved with a simple two-pointer approach, where we iterate through both strings simultaneously and append characters in alternating order.  
- **Algorithm invariant:** At each iteration, we add one character from `word1` (if available) and then one character from `word2` (if available). This ensures the alternating order.  
- **Why this works:** The loop runs until the result string reaches the combined length of both inputs, ensuring all characters are added in the correct order.  

### 3.2 Algorithm Strategy

1. Initialize two pointers `i` and `j` to 0, representing the current index in `word1` and `word2`, respectively.  
2. Pre-allocate memory for the result string to avoid repeated reallocations.  
3. In a loop that runs until the result string reaches the combined length of both inputs:  
    - If `i` is within bounds of `word1`, append `word1[i]` to the result and increment `i`.  
    - If `j` is within bounds of `word2`, append `word2[j]` to the result and increment `j`.  
4. Return the final result string.

- **Step 4:** `j < 3` → append `'q'`, `j = 2`  
- **Step 5:** `i < 3` → append `'c'`, `i = 3`  
- **Step 6:** `j < 3` → append `'r'`, `j = 3`

**Final result:** `"apbqcr"`

## 5. Complexity Analysis

- **Time Complexity:** $O(n + m)$, where $n = \text{length of } word1$, $m = \text{length of } word2$  
    - **Why:** We iterate through both strings once, performing constant work per character.  

- **Space Complexity:** $O(n + m)$  
    - **Why:** The result string stores all characters from both inputs, and no additional data structures are used.  

---

## 6. Code Solution (C++)

```cpp
class Solution {
 public:
  string mergeAlternately(string word1, string word2) {
    int i = 0, j = 0;
    string result;
    result.reserve(word1.length() + word2.length());
    while (result.length() < word1.length() + word2.length()) {
      if (i < word1.length()) {
        result.push_back(word1[i]);
        i++;
      }
      if (j < word2.length()) {
        result.push_back(word2[j]);
        j++;
      }
    }
    return result;
  }
};
```
