

# 49. Group Anagrams

## 0. Problem Metadata

- **Difficulty:** Medium  
- **Topics/Tags:** Hash Map, String, Sorting  
- **Pattern Category:** Hash Map - Key Transformation

## 1. Problem Statement

> Given an array of strings `strs`, group the anagrams together. You can return the answer in **any order**.

> **Example 1:**  
> Input: `strs = ["eat","tea","tan","ate","nat","bat"]`  
> Output: `[["bat"],["nat","tan"],["ate","eat","tea"]]`  
> Explanation:  
> - There is no string in `strs` that can be rearranged to form `"bat"`.  
> - The strings `"nat"` and `"tan"` are anagrams as they can be rearranged to form each other.  
> - The strings `"ate"`, `"eat"`, and `"tea"` are anagrams as they can be rearranged to form each other.  

> **Example 2:**  
> Input: `strs = [""]`  
> Output: `[[""]]`  

> **Example 3:**  
> Input: `strs = ["a"]`  
> Output: `[["a"]]`  

---

## 2. Constraints & Key Observations

- **Constraints:**  
    - `1 <= strs.length <= 10^4`  
    - `0 <= strs[i].length <= 100`  
    - `strs[i]` consists of lowercase English letters.  

- **What constraints tell us:**  
    - `strs.length <= 10^4` implies that O(n) algorithms are acceptable, but O(n²) may be too slow.  
    - `strs[i].length <= 100` means sorting each string is feasible (O(k log k) per string, where k ≤ 100).  

- **Key observations:**  
    - Anagrams share the same sorted character sequence. For example, `"eat"` and `"tea"` both sort to `"aet"`.  
    - Using the sorted string as a key in a hash map allows grouping all anagrams under the same key.  

- **Edge cases to handle (based on actual constraints):**  
    - Empty strings (e.g., `""`) must be grouped into their own list.  
    - Strings with a single character (e.g., `"a"`) must be grouped into their own list.

## 3. Solution Development

### 3.1 Core Intuition

- **The "Aha!" moment:** Sorting the characters of each string creates a unique key for all anagrams.  
- **Algorithm invariant:** At any point, the hash map maps a sorted string key to a list of original strings that are anagrams of each other.  
- **Why this works:** Anagrams are permutations of each other, so sorting their characters produces identical keys.  

### 3.2 Algorithm Strategy

1. Initialize an empty hash map (`unordered_map<string, vector<string>>`) to map sorted keys to groups of anagrams.  
2. Iterate through each string in the input array:  
    - Sort the characters of the string to generate a key.  
    - Add the original string to the corresponding group in the hash map.  
3. Extract all groups from the hash map and return them as the final result.

## 4. Example Walkthrough

**Input:** `strs = ["eat","tea","tan","ate","nat","bat"]`  

**Initial state:**  
- `anagramMap` is empty.  

**Execution trace:**  
- **Step 1:** Process `"eat"` → sorted key is `"aet"` → add `"eat"` to `anagramMap["aet"]`.  
- **Step 2:** Process `"tea"` → sorted key is `"aet"` → add `"tea"` to `anagramMap["aet"]`.  
- **Step 3:** Process `"tan"` → sorted key is `"ant"` → add `"tan"` to `anagramMap["ant"]`.  
- **Step 4:** Process `"ate"` → sorted key is `"aet"` → add `"ate"` to `anagramMap["aet"]`.  
- **Step 5:** Process `"nat"` → sorted key is `"ant"` → add `"nat"` to `anagramMap["ant"]`.  
- **Step 6:** Process `"bat"` → sorted key is `"abt"` → add `"bat"` to `anagramMap["abt"]`.  

**Final result:**  
- `anagramMap` contains:  
    - `"aet"` → `["eat", "tea", "ate"]`  
    - `"ant"` → `["tan", "nat"]`  
    - `"abt"` → `["bat"]`  
- Output: `[["bat"],["nat","tan"],["ate","eat","tea"]]`

## 5. Complexity Analysis

- **Time Complexity:** $O(n \cdot k \log k)$  
    - $n$ is the number of strings.  
    - $k$ is the maximum length of a string.  
    - Sorting each string takes $O(k \log k)$, and there are $n$ strings.  

- **Space Complexity:** $O(n \cdot k)$  
    - The hash map stores all strings, with each string taking $O(k)$ space.

## 6. Code Solution (C++)

```cpp
class Solution {

public:

    vector<vector<string>> groupAnagrams(vector<string>& strs) {

        unordered_map<string, vector<string>> anagramMap;

        for(int i= 0; i<strs.size(); i++){

            string temp = strs[i];

            sort(temp.begin(), temp.end());

            anagramMap[temp].push_back(strs[i]);

        }

        vector<vector<string>> result;

        for(auto& pair : anagramMap) {

            result.push_back(pair.second);

        }

        return result;

    }

};
```
