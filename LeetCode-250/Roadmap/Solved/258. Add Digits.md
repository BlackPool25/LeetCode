

# 258. Add Digits

## 1. Problem Statement

> Given an integer `num`, repeatedly add all its digits until the result has only one digit, and return it.

> **Example 1:**  
> Input: `num = 38`  
> Output: `2`  
> Explanation: The process is  
> `38 --> 3 + 8 --> 11`  
> `11 --> 1 + 1 --> 2`  
> Since `2` has only one digit, return it.

> **Example 2:**  
> Input: `num = 0`  
> Output: `0`

---

## 2. Constraints & Key Observations

- **Constraints:**  
    - `0 <= num <= 2^31 - 1`

- **What constraints tell us:**  
    - `num` can be as large as `2^31 - 1`, but the loop-based solution is efficient enough for this range.

- **Key observations:**  
    - The process is deterministic and terminates because each iteration reduces the number of digits.  
    - The final result is the **digital root** of the number, which has a mathematical formula.

- **Edge cases to handle (based on actual constraints):**  
    - `num = 0` → return `0`  
    - `num` is already a single-digit number → return `num` immediately

---

## 3. Solution Development

### 3.1 Core Intuition

- **The "Aha!" moment:**  
  Repeatedly summing digits until a single digit is obtained is equivalent to computing the **digital root** of the number.

- **Algorithm invariant:**  
  At each iteration, the number is reduced by summing its digits, ensuring that the number of digits decreases until it becomes a single digit.

- **Why this works:**  
  The loop continues until the number is less than 10, which guarantees the result is a single-digit number.

---

### 3.2 Algorithm Strategy

1. **Iterate while the number has more than one digit** (`num >= 10`).  
2. **Extract the last digit** using `num % 10`.  
3. **Remove the last digit** using integer division `num /= 10`.  
4. **Add the extracted digit** to the remaining number.  
5. **Repeat** until the number is a single digit.

---

## 4. Example Walkthrough

**Input:** `num = 38`

**Initial state:**  
- `num = 38`

**Execution trace:**

- **Step 1:**  
  - `temp = 38 % 10 = 8`  
  - `num = 38 / 10 = 3`  
  - `num += temp → 3 + 8 = 11`  
  - `num = 11` (still ≥ 10 → continue)

- **Step 2:**  
  - `temp = 11 % 10 = 1`  
  - `num = 11 / 10 = 1`  
  - `num += temp → 1 + 1 = 2`  
  - `num = 2` (now < 10 → exit loop)

**Final result:** `2`

---

## 5. Complexity Analysis

- **Time Complexity:** $O(\log_{10} \text{num})$  
  - **Why:** Each iteration reduces the number of digits by at least one, and the number of digits is logarithmic in `num`.

- **Space Complexity:** $O(1)$  
  - **Why:** Only a few variables are used, and no additional data structures are allocated.

---

## 6. Code Solution (C++)

```cpp
class Solution {
public:
    int addDigits(int num) {
        while (num >= 10) {
            int temp = num % 10;
            num /= 10;
            num += temp;
        }
        return num;
    }
};
```

## 7. Key Takeaways & Pattern Recognition

### 🎯 Pattern Recognition

- **This pattern applies when:**  
    - You need to **process digits of a number iteratively**  
    - The problem can be solved by **reducing the number step-by-step** until a base case is reached  
    - The input is a **non-negative integer** and the output is a **single-digit result**

- **Pattern Structure (reusable template):**

```cpp
// Simulation - Iterative Digit Processing
// Process each digit of the number until it becomes a single digit

int num = [initial_value];  // The input number

while (num >= 10) {
    int temp = num % 10;     // Extract last digit
    num /= 10;               // Remove last digit
    num += temp;             // Add extracted digit to remaining number
}

return num;  // Final single-digit result
```

---

### 💡 Key Insights

- **The core idea** is to reduce the number by summing its digits iteratively.  
- **Avoiding recursion or loops** is possible using the **digital root formula**:  
  - If `num == 0`, return `0`  
  - Else if `num % 9 == 0`, return `9`  
  - Else return `num % 9`  
- **Common mistake:** Forgetting to handle the case where `num == 0` explicitly.
