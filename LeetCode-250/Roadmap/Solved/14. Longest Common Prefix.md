

# 14. Longest Common Prefix

## 0. Problem Metadata

- **Difficulty:** Easy
- **Topics/Tags:** Array, String
- **Pattern Category:** **Vertical Scan – Column‑wise Comparison**
- **LeetCode Link:** https://leetcode.com/problems/longest-common-prefix/

## 1. Problem Statement

> **Write a function to find the longest common prefix string amongst an array of strings.**  
> If there is no common prefix, return an empty string `""`.

**Example 1:**

**Input:** `strs = ["flower","flow","flight"]`  
**Output:** `"fl"`  
**Explanation:** The longest common prefix among all strings is `"fl"`.

**Example 2:**

**Input:** `strs = ["dog","racecar","car"]`  
**Output:** `""`  
**Explanation:** There is no common prefix among the input strings.

**Constraints:**

- `1 <= strs.length <= 200`
- `0 <= strs[i].length <= 200`
- `strs[i]` consists of only lowercase English letters if it is non‑empty.

---

## 2. Constraints & Key Observations

- **Constraints:**
  - `1 ≤ strs.length ≤ 200`
  - `0 ≤ strs[i].length ≤ 200`
  - All strings contain only lowercase letters.
- **What constraints tell us:**
  - The input size is small enough for an $O(n \cdot m)$ solution, where $n$ is the number of strings and $m$ is the length of the shortest string.
  - Since `strs.length` is at least 1, we can safely reference `strs[0]` without an empty‑array check.
- **Key observations:**
  - The common prefix must be a prefix of the first string; no longer prefix can exist.
  - The prefix can be built character by character, stopping as soon as any string diverges.
- **Edge cases to handle:**
  - One string in the array → the prefix is the string itself.
  - One or more empty strings → the prefix is `""`.
  - All strings identical → the prefix is the entire string.

---

## 3. Solution Development

### 3.1 Core Intuition

- **Aha!** The longest common prefix must appear at the same index in every string.  
- **Invariant:** After processing the first `k` characters, `commonpre` contains the exact common prefix of length `k` for all strings examined so far.  
- **Why it works:** By comparing the `i`‑th character of the first string with the `i`‑th character of every other string, we guarantee that any mismatch immediately ends the prefix search.

### 3.2 Algorithm Strategy

1. **Handle trivial case** – if the array is empty, return `""` (not needed by constraints but kept for safety).  
2. **Iterate over each character position `i` of the first string** (outer loop).  
3. **For each position, compare that character with the same position in all other strings** (inner loop).  
   - If any string is shorter than `i+1`, or the characters differ, return the prefix accumulated so far.  
4. **If all strings match at position `i`, append the character to `commonpre` and continue**.  
5. **After the outer loop completes, return `commonpre`** – all characters matched.

## 5. Complexity Analysis

- **Time Complexity:** $O(n \cdot m)$  
  - $n$ = number of strings (≤ 200)  
  - $m$ = length of the first string (≤ 200)  
  - Each character of the first string is compared with the same position in all other strings until a mismatch or end of a string is found.
- **Space Complexity:** $O(1)$  
  - Only a few integer counters and a result string of length at most $m$ are used.  
  - No additional data structures that grow with input size.

## 6. Code Solution (C++)

```cpp
class Solution { public: string longestCommonPrefix(vector<string>& strs) { if(strs.size() == 0) return ""; int iteration = 0; string commonpre = ""; for(int i = 0; i < strs[0].length() ; i++){ char cur = strs[0][i]; // Start with the character of the reference string 
for(int j=1;j<strs.size(); j++)
{ if(iteration == strs[j].length()) return commonpre; // Check if the current character is out of bounds
 if(strs[j][i] != cur) return commonpre; // check if the character matches if not return the previously stored commonpre } commonpre += cur; // Add the current char with the previously stored common prefix iteration += 1; // Increment the count for the letters scanned for in the vertical search } return commonpre; } };
```

## 7. Key Takeaways & Pattern Recognition

### 🎯 Pattern Recognition

- **This pattern applies when:**
  - You need to compare elements at the same index across multiple sequences.
  - The answer can be built incrementally by verifying each position.
  - A mismatch or boundary condition immediately terminates the search.
- **Pattern Structure (reusable template):**

```cpp
// Vertical Scan – Column‑wise Comparison
string result = "";
for (int i = 0; i < reference.length(); ++i) {
    char cur = reference[i];
    for (int j = 1; j < strings.size(); ++j) {
        if (i >= strings[j].length() || strings[j][i] != cur) {
            return result;   // mismatch or out of bounds
        }
    }
    result += cur;   // all strings matched at position i
}
return result;
```

### 💡 Key Insights

- The common prefix **must** be a prefix of the first string; no longer prefix exists.
- Comparing column‑by‑column guarantees that any divergence stops the search.
- The algorithm stops at the earliest possible point, ensuring optimal time for small inputs.
