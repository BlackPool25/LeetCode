

# 26. Remove Duplicates from Sorted Array

## 1. Problem Statement

> Given a sorted array `nums`, remove the duplicates in-place such that each unique element appears only once. The relative order should be kept the same. Since the array is sorted, the algorithm must not allocate extra space for another array. The result should be placed in the first part of the array, and the length of the final result is returned. The array may be modified beyond the first `k` elements.

> **Example 1:**  
> Input: `nums = [1,1,2]`  
> Output: `2`  
> Explanation: The first two elements are `1` and `2`, which are unique. The array is modified to `[1,2,2]` (the third element is not considered).  

> **Example 2:**  
> Input: `nums = [0,0,1,1,1,2,2,3,3,4]`  
> Output: `5`  
> Explanation: The first five elements are `0,1,2,3,4`, which are unique. The array is modified to `[0,1,2,3,4,2,2,3,3,4]`.

---

## 2. Constraints & Key Observations

- **Constraints:**
    - `1 <= nums.length <= 3 * 10^4`
    - `-10^5 <= nums[i] <= 10^5`
    - `nums` is **sorted in non-decreasing order**

- **What constraints tell us:**
    - The array is **guaranteed to be sorted**, which allows us to compare adjacent elements to detect duplicates.
    - The **input size is large** (up to 30,000 elements), so **O(n²) algorithms are not acceptable**.
    - **In-place modification** is required, so **no extra space** for a new array.

- **Key observations:**
    - Duplicates are **consecutive** due to the sorted property.
    - We can **overwrite** the array in-place by maintaining a **"front"** of the array with unique elements.

- **Edge cases to handle:**
    - Single-element array (e.g., `[5]` → return `1`)
    - All elements the same (e.g., `[2,2,2]` → return `1`)
    - No duplicates (e.g., `[1,2,3]` → return `3`)

## 3. Solution Development

### 3.1 Core Intuition

- **The "Aha!" moment:** Since the array is sorted, duplicates are **consecutive**, so we can **compare adjacent elements** to detect and skip duplicates.
- **Algorithm invariant:** At any point, the subarray `nums[0...slow]` contains only **unique elements**.
- **Why this works:** By maintaining the invariant, we ensure that the final array up to index `slow` contains all unique elements in the original order.

### 3.2 Algorithm Strategy

1. Initialize a **slow pointer** at index `0` to track the **front of the unique array**.
2. Iterate with a **fast pointer** from index `1` to the end of the array.
3. For each element at `fast`, if it is **different** from the element at `slow`, increment `slow` and **overwrite** `nums[slow]` with `nums[fast]`.
4. After processing all elements, the length of the unique array is `slow + 1`.

---

## 4. Example Walkthrough

**Input:** `nums = [1,1,2]`

**Initial state:**
- `slow = 0`, `fast = 1`, `nums = [1,1,2]`

**Execution trace:**
- **Step 1:** `fast = 1`, `nums[fast] = 1` == `nums[slow] = 1` → do nothing.
- **Step 2:** `fast = 2`, `nums[fast] = 2` != `nums[slow] = 1` → increment `slow` to `1`, set `nums[1] = 2`.
- **Final state:** `nums = [1,2,2]`, `slow = 1` → return `slow + 1 = 2`.

---

## 5. Complexity Analysis

- **Time Complexity:** $O(n)$  
    - **Why:** A single pass through the array with two pointers (fast and slow), each step taking constant time.

- **Space Complexity:** $O(1)$  
    - **Why:** Only two pointers are used, and the array is modified in-place with no additional data structures.

---

## 6. Code Solution (C++)

```cpp
class Solution {
public:
    int removeDuplicates(vector<int>& nums) {
        if (nums.empty()) return 0;

        int slow = 0;
        for (int fast = 1; fast < nums.size(); ++fast) {
            if (nums[fast] != nums[slow]) {
                slow++;
                nums[slow] = nums[fast];
            }
        }
        return slow + 1;
    }
};
```

### 🎯 Pattern Recognition

### 💡 Key Insights

- The **sorted property** is essential for this approach to work.
- The **in-place modification** avoids using extra space.
- A **common mistake** is to forget to increment the slow pointer **before** overwriting the array.
