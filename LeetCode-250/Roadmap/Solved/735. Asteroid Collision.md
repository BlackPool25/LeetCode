## 1. Problem Statement

> **We are given an array `asteroids` of integers representing asteroids in a row. The indices of the asteroid in the array represent their relative position in space.**  
>  
> **For each asteroid, the absolute value represents its size, and the sign represents its direction (positive meaning right, negative meaning left). Each asteroid moves at the same speed.**  
>  
> **Find out the state of the asteroids after all collisions. If two asteroids meet, the smaller one will explode. If both are the same size, both will explode. Two asteroids moving in the same direction will never meet.**  
>  
> **Example 1:**  
> Input: `asteroids = [5,10,-5]`  
> Output: `[5,10]`  
> Explanation: The 10 and -5 collide resulting in 10. The 5 and 10 never collide.  
>  
> **Example 2:**  
> Input: `asteroids = [8,-8]`  
> Output: `[]`  
> Explanation: The 8 and -8 collide exploding each other.  
>  
> **Example 3:**  
> Input: `asteroids = [10,2,-5]`  
> Output: `[10]`  
> Explanation: The 2 and -5 collide resulting in -5. The 10 and -5 collide resulting in 10.  
>  
> **Example 4:**  
> Input: `asteroids = [3,5,-6,2,-1,4]`  
> Output: `[-6,2,4]`  
> Explanation: The asteroid -6 makes the asteroid 3 and 5 explode, and then continues going left. On the other side, the asteroid 2 makes the asteroid -1 explode and then continues going right, without reaching asteroid 4.

## 2. Constraints & Key Observations

- **Constraints:**
    - `2 <= asteroids.length <= 10^4`
    - `-1000 <= asteroids[i] <= 1000`
    - `asteroids[i] != 0`

- **What constraints tell us:**
    - Input size is large enough to require an efficient algorithm (O(n) is ideal).
    - No zero values, so no need to handle zero-movement cases.

- **Key observations:**
    - Collisions only occur when a **right-moving** asteroid (`+ve`) is **followed by** a **left-moving** asteroid (`-ve`).
    - The order of processing is critical: left to right, as collisions are determined by relative positions.
    - A **stack** is ideal for simulating this behavior, as it allows us to track potential collisions in reverse order.

- **Edge cases to handle (based on actual constraints):**
    - All asteroids moving in the same direction (no collisions).
    - All asteroids moving in opposite directions (e.g., `[5, -5]` → `[]`).
    - A single asteroid (impossible due to constraints, but code must handle empty stack).

## 3. Solution Development

### 3.1 Core Intuition

- **The "Aha!" moment:**  
  Collisions only happen when a **right-moving** asteroid is **followed by** a **left-moving** one. This allows us to use a **stack** to simulate the process efficiently.

- **Algorithm invariant:**  
  The stack always contains the **surviving asteroids** in the correct order, with potential collisions resolved as we process each asteroid.

- **Why this works:**  
  By iterating through the array and using a stack to simulate collisions, we ensure that each asteroid is processed exactly once, and only when a collision is possible.

---

### 3.2 Algorithm Strategy

1. **Initialize an empty stack** to keep track of surviving asteroids.
2. **Iterate through each asteroid** in the input array.
3. **For each asteroid:**
    - While the asteroid is **alive** and the stack is not empty, and the **top of the stack is moving right** while the current asteroid is moving **left**, check for a collision.
    - If the current asteroid is **larger**, pop the stack (the top asteroid explodes).
    - If the current asteroid is **smaller**, mark it as dead (do not push to the stack).
    - If they are **equal**, pop the stack and mark the current asteroid as dead.
4. **If the asteroid is still alive**, push it to the stack.
5. **Return the stack** as the final state.

## 5. Complexity Analysis

- **Time Complexity:** `O(n)`  
  Each asteroid is pushed and popped at most once from the stack.

- **Space Complexity:** `O(n)`  
  The stack can grow to the size of the input array in the worst case (no collisions).

## 6. Code Solution

```cpp
class Solution {
public:
    vector<int> asteroidCollision(vector<int>& asteroids) {
        stack<int> myStack;
        for (int asteroid : asteroids) {
            bool alive = true;
            while (alive && !myStack.empty() && myStack.top() > 0 && asteroid < 0) {
                if (myStack.top() < -asteroid) {
                    myStack.pop();
                } else if (myStack.top() == -asteroid) {
                    myStack.pop();
                    alive = false;
                } else {
                    alive = false;
                }
            }
            if (alive) {
                myStack.push(asteroid);
            }
        }
        vector<int> result;
        while (!myStack.empty()) {
            result.push_back(myStack.top());
            myStack.pop();
        }
        reverse(result.begin(), result.end());
        return result;
    }
};
```
