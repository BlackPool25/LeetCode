

# 121. Best Time to Buy and Sell Stock

## 1. Problem Statement

> You are given an array `prices` where `prices[i]` is the price of a given stock on the `ith` day.  
>  
> You want to maximize your profit by choosing a **single day** to buy one stock and choosing a **different day in the future** to sell that stock.  
>  
> Return the maximum profit you can achieve from this transaction. If you cannot achieve any profit, return `0`.  

**Example 1:**  
Input: `prices = [7,1,5,3,6,4]`  
Output: `5`  
Explanation: Buy on day 2 (price = 1) and sell on day 5 (price = 6), profit = 6-1 = 5. Note that buying on day 2 and selling on day 1 is not allowed because you must buy before you sell.  

**Example 2:**  
Input: `prices = [7,6,4,3,1]`  
Output: `0`  
Explanation: In this case, no transactions are done and the max profit = 0.

---

## 2. Constraints & Key Observations

- **Constraints:**  
    - `1 <= prices.length <= 10^5`  
    - `0 <= prices[i] <= 10^4`  

- **What constraints tell us:**  
    - `n <= 10^5` implies that any $O(n^2)$ solution is infeasible; we must aim for $O(n)$ or better.  
    - Prices are non-negative, so no need to handle negative values.  

- **Key observations:**  
    - The optimal solution must involve buying at the lowest possible price before a higher price.  
    - The problem reduces to finding the maximum difference `prices[j] - prices[i]` where `j > i`.  

- **Edge cases to handle (based on actual constraints):**  
    - Single-element array (return `0` since no sell is possible).  
    - Strictly decreasing prices (return `0`).  
    - All prices equal (return `0`).

## 3. Solution Development

### 3.1 Core Intuition

- **The "Aha!" moment:** The maximum profit is determined by the **lowest price seen so far** and the **highest possible profit from that price**.  
- **Algorithm invariant:** At any point in the iteration, `min_price` holds the minimum price from the start up to the current index.  
- **Why this works:** By maintaining the minimum price and recalculating profit at each step, we ensure that we always consider the best possible buy day before the current sell day.  

### 3.2 Algorithm Strategy

1. Initialize `min_price` to the first element and `max_profit` to `0`.  
2. Iterate through each price in the array:  
    - If the current price is lower than `min_price`, update `min_price`.  
    - Otherwise, calculate the profit if sold at the current price and update `max_profit` if this profit is greater than the current `max_profit`.  
3. Return `max_profit` after processing all prices.

## 4. Example Walkthrough

**Input:** `prices = [7,1,5,3,6,4]`  

**Initial state:**  
- `min_price = 7`  
- `max_profit = 0`  

**Execution trace:**  
- **Step 1:** `price = 1`  
    - `1 < 7` → update `min_price = 1`  
    - `max_profit` remains `0`  
- **Step 2:** `price = 5`  
    - `5 - 1 = 4 > 0` → update `max_profit = 4`  
- **Step 3:** `price = 3`  
    - `3 - 1 = 2 < 4` → no change to `max_profit`  
- **Step 4:** `price = 6`  
    - `6 - 1 = 5 > 4` → update `max_profit = 5`  
- **Step 5:** `price = 4`  
    - `4 - 1 = 3 < 5` → no change to `max_profit`  

**Final result:** `5`

## 5. Complexity Analysis

- **Time Complexity:** $O(n)$  
    - **Why:** Single pass through the array with constant-time operations per element.  

- **Space Complexity:** $O(1)$  
    - **Why:** Only two variables (`min_price`, `max_profit`) are used, regardless of input size.  

---

## 6. Code Solution (C++)

```cpp
class Solution {

public:

    int maxProfit(vector<int>& prices) {

        int min_price = prices[0], max_profit = 0;

        for(int price : prices){

            if(price < min_price) min_price = price;

            if((price - min_price) > max_profit) max_profit = price - min_price;

        }

        return max_profit;

    }

};
```

## 7. Key Takeaways & Pattern Recognition

### 🎯 Pattern Recognition

- **This pattern applies when:**  
    - You need to find the **maximum difference** between two elements in an array where the **larger element comes after the smaller one**.  
    - The input is **processed in a single pass**, and **extremes (min/max) are tracked dynamically**.  

- **Pattern Structure (reusable template):**

```cpp
// "Single Pass - Track Extremes"
// Track the minimum price seen so far and calculate profit at each step

int min_price = prices[0], max_profit = 0;

for(int price : prices) {
    if(price < min_price) {
        min_price = price;  // Update minimum price
    } else {
        int current_profit = price - min_price;
        if(current_profit > max_profit) {
            max_profit = current_profit;  // Update maximum profit
        }
    }
}

return max_profit;
```

### 💡 Key Insights

- **Technical insight:** The algorithm avoids checking all pairs by maintaining the **minimum price seen so far**, reducing the problem to a single pass.  
- **Optimization:** No nested loops are needed; the solution is $O(n)$ time and $O(1)$ space.  
- **Common mistake:** Forgetting to update `min_price` when a lower price is found, which would lead to incorrect profit calculations.
