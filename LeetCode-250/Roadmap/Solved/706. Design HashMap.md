## 1. Problem Statement

> Design a HashMap without using any built-in hash table libraries.  
>  
> Implement the `MyHashMap` class:  
>  
> - `MyHashMap()` initializes the object with an empty map.  
> - `void put(int key, int value)` inserts a `(key, value)` pair into the HashMap. If the `key` already exists in the map, update the corresponding `value`.  
> - `int get(int key)` returns the `value` to which the specified `key` is mapped, or `-1` if this map contains no mapping for the `key`.  
> - `void remove(int key)` removes the `key` and its corresponding `value` if the map contains the mapping for the `key`.  
>  
> **Example 1:**  
> Input: `["MyHashMap", "put", "put", "get", "get", "put", "get", "remove", "get"]`  
> `[[], [1, 1], [2, 2], [1], [3], [2, 1], [2], [2], [2]]`  
> Output: `[null, null, null, 1, -1, null, 1, null, -1]`  
>  
> **Explanation:**  
> MyHashMap myHashMap = new MyHashMap();  
> myHashMap.put(1, 1); // The map is now [[1,1]]  
> myHashMap.put(2, 2); // The map is now [[1,1], [2,2]]  
> myHashMap.get(1);    // return 1, The map is now [[1,1], [2,2]]  
> myHashMap.get(3);    // return -1 (i.e., not found), The map is now [[1,1], [2,2]]  
> myHashMap.put(2, 1); // The map is now [[1,1], [2,1]] (i.e., update the existing value)  
> myHashMap.get(2);    // return 1, The map is now [[1,1], [2,1]]  
> myHashMap.remove(2); // remove the mapping for 2, The map is now [[1,1]]  
> myHashMap.get(2);    // return -1 (i.e., not found), The map is now [[1,1]]

## 2. Constraints & Key Observations

- **Constraints:**  
    - `0 <= key, value <= 10^6`  
    - At most `10^4` calls will be made to `put`, `get`, and `remove`.  

- **What constraints tell us:**  
    - `10^4` operations suggest that average-case $O(1)$ time per operation is acceptable.  
    - Key range up to $10^6$ implies that a naive array-based approach (size $10^6$) would be memory-inefficient.  

- **Key observations:**  
    - A custom hash function is used to map keys to a smaller range of indices.  
    - Collision resolution is handled via **chaining** (each bucket is a list of key-value pairs).  
    - The hash function is designed to minimize collisions and distribute keys uniformly.  

- **Edge cases to handle (based on actual constraints):**  
    - Keys that hash to the same bucket (collision).  
    - Keys that are updated (i.e., `put` on an existing key).  
    - Keys that are removed (i.e., `remove` on a key that exists).

## 3. Solution Development

### 3.1 Core Intuition

- **The "Aha!" moment:**  
  Use a **hash table with chaining** to handle collisions and support efficient insertions, lookups, and deletions.  

- **The hash function's role:**  
  Maps keys to a smaller range of indices (via a custom hash function) to reduce memory usage.  

- **The algorithm's invariant:**  
  Each key is mapped to a specific bucket (via the hash function), and within that bucket, entries are stored as key-value pairs.  

---

### 3.2 Algorithm Strategy

1. **Initialization:**  
   - Create a vector of buckets (each bucket is a list of key-value pairs).  
   - Use a custom hash function to compute the index for each key.  

2. **Put Operation:**  
   - Compute the index using the hash function.  
   - Iterate through the bucket's entries:  
     - If the key exists, update its value.  
     - If not, append a new key-value pair to the bucket.  

3. **Get Operation:**  
   - Compute the index using the hash function.  
   - Iterate through the bucket's entries:  
     - If the key is found, return its value.  
     - If not, return `-1`.  

4. **Remove Operation:**  
   - Compute the index using the hash function.  
   - Use `remove_if` to find and erase the entry with the specified key.

## 5. Complexity Analysis

- **Time Complexity:**  
  - **Average Case:** $O(1)$ for `put`, `get`, and `remove` (assuming uniform hash distribution).  
  - **Worst Case:** $O(n)$ if all keys hash to the same bucket (collisions).  

- **Space Complexity:**  
  - $O(n)$, where $n$ is the number of key-value pairs inserted.

## 6. Code Implementation

```cpp
class MyHashMap {
public:
    vector<vector<pair<int, int>>> table;
    int size;

    MyHashMap() {
        size = 10000;
        table.resize(size);
    }

    int hash(int key) {
        int h = key;
        h = ((h >> 16) ^ h) * 0x45d9f3b;
        h = ((h >> 16) ^ h) * 0x45d9f3b;
        h = (h >> 16) ^ h;
        return h & 0x7FFFFFFF;
    }

    void put(int key, int value) {
        int index = hash(key) % size;

        for (auto& item : table[index]) {
            if (item.first == key) {
                item.second = value;
                return;
            }
        }
        table[index].emplace_back(key, value);
    }

    int get(int key) {
        int index = hash(key) % size;

        for (auto& item : table[index]) {
            if (item.first == key) {
                return item.second;
            }
        }
        return -1;
    }

    void remove(int key) {
        int index = hash(key) % size;

        auto& bucket = table[index];
        auto it = remove_if(bucket.begin(), bucket.end(), [key](const pair<int, int>& element) {
            return element.first == key;
        });

        bucket.erase(it, bucket.end());
    }
};
```
