## 1. Problem Statement

> Design a HashMap without using any built-in hash table libraries.  
>  
> Implement the `MyHashMap` class:  
>  
> - `MyHashMap()` initializes the object with an empty map.  
> - `void put(int key, int value)` inserts a `(key, value)` pair into the HashMap. If the `key` already exists in the map, update the corresponding `value`.  
> - `int get(int key)` returns the `value` to which the specified `key` is mapped, or `-1` if this map contains no mapping for the `key`.  
> - `void remove(int key)` removes the `key` and its corresponding `value` if the map contains the mapping for the `key`.  
>  
> **Example 1:**  
> Input: `["MyHashMap", "put", "put", "get", "get", "put", "get", "remove", "get"]`  
> `[[], [1, 1], [2, 2], [1], [3], [2, 1], [2], [2], [2]]`  
> Output: `[null, null, null, 1, -1, null, 1, null, -1]`  
>  
> **Explanation:**  
> MyHashMap myHashMap = new MyHashMap();  
> myHashMap.put(1, 1); // The map is now [[1,1]]  
> myHashMap.put(2, 2); // The map is now [[1,1], [2,2]]  
> myHashMap.get(1);    // return 1, The map is now [[1,1], [2,2]]  
> myHashMap.get(3);    // return -1 (i.e., not found), The map is now [[1,1], [2,2]]  
> myHashMap.put(2, 1); // The map is now [[1,1], [2,1]] (i.e., update the existing value)  
> myHashMap.get(2);    // return 1, The map is now [[1,1], [2,1]]  
> myHashMap.remove(2); // remove the mapping for 2, The map is now [[1,1]]  
> myHashMap.get(2);    // return -1 (i.e., not found), The map is now [[1,1]]

    - Separate chaining (using vectors of pairs) is used to resolve collisions.  
    - The hash function uses bit manipulation to reduce collisions.  

- **Edge cases to handle (based on actual constraints):**  
    - Keys that hash to the same bucket (collision resolution).  
    - Updating an existing key (must replace value, not insert new).  
    - Removing a key that does not exist (no-op).

## 3. Solution Development

### **Core Intuition**

The solution uses a **hash table with separate chaining** to handle collisions. Each bucket in the hash table is a vector of `(key, value)` pairs. A custom hash function is used to map keys to indices in the table.

### **Algorithm Strategy**

1. **Hash Table Initialization:**  
   - A fixed-size vector (`table`) is used to store buckets.  
   - The size is chosen to be large enough to minimize collisions (e.g., `10^4` or `10^5`).  

2. **Hash Function:**  
   - A custom hash function is implemented using bit manipulation to ensure even distribution of keys.  
   - The function avoids negative indices by using unsigned integers and masking.  

3. **Collision Resolution (Separate Chaining):**  
   - Each bucket is a vector of `(key, value)` pairs.  
   - When a key is inserted, it is added to the corresponding bucket.  
   - When a key is updated, it is found in the bucket and its value is replaced.  
   - When a key is removed, it is erased from the bucket.

## 6. Code Implementation

```cpp
class MyHashMap {
public:
    MyHashMap() : size(10000), table(size) {}

    int hash(int key) {
        unsigned int k = static_cast<unsigned int>(key);
        k = ((k >> 16) ^ k) * 0x45d9f3b;
        k = ((k >> 16) ^ k) * 0x45d9f3b;
        k = (k >> 16) ^ k;
        return static_cast<int>(k & 0x7FFFFFFF);
    }

    void put(int key, int value) {
        int index = hash(key) % size;
        for (auto& item : table[index]) {
            if (item.first == key) {
                item.second = value;
                return;
            }
        }
        table[index].emplace_back(key, value);
    }

    int get(int key) {
        int index = hash(key) % size;
        for (auto& item : table[index]) {
            if (item.first == key) {
                return item.second;
            }
        }
        return -1;
    }

    void remove(int key) {
        int index = hash(key) % size;
        auto& bucket = table[index];
        auto it = std::remove_if(bucket.begin(), bucket.end(), [key](const std::pair<int, int>& element) {
            return element.first == key;
        });
        bucket.erase(it, bucket.end());
    }

private:
    int size;
    std::vector<std::vector<std::pair<int, int>>> table;
};
```
